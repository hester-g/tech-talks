Some useful

commands

Insert mode stuff

  • i - to the left of cursor
  • a - to the right of cursor
  • I - beginning of line
  • A - end of line
  • o - new line below cursor
  • O - new line above cursor

Moving around

  • hjkl (or arrow keys)
  • 0 or ^ - start of line
  • $ - end of line
  • w - move cursor to the next word
  • b - move cursor back to previous word

Searching

  • / - search, moving forward from your position
  • ? - search, moving backward from your position
  • n - look at the next result of search

Deleting, yanking, putting

  • dd - delete (cut) line
  • yy - yank (copy) line
  • p - put below
  • P - put above
  • d[where-to] - delete from cursor to specified location
  • [num]dd - e.g. 10dd, delete 10 lines including this one

More modificationy stuff

  • r[char] - replace current character with what's specified
  • x - delete current character
  • cw - change word from cursor
  • cc - change line
  • ciw - change inside word
  • ~ - change case

Misc general good stuff

  • :set number
  • :set nonumber
  • u - undo last command
  • U - undo all changes to file
  • [how-many-times][command][where-to] e.g. 2dw

Find and replace!

  • :[where]s/replace-me/with-this/g
  • :%s/replace-me/with-this/g
  • :3,45s/replace-me/with-this/g
